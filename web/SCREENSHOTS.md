# 官网截图清单（NAS Music TV）· 已定稿

官网截图位采用「空位 + 自动识别」机制：

- 图片放进 `web/public/screens/` → 官网对应位置自动显示（无需改代码、无需改 JSON）。
- 图片没放 → 该位置显示虚线占位框，框里直接写出**需要的文件名、尺寸、画面内容**，不会破图。
- 支持后缀 `.png` / `.jpg` / `.jpeg` / `.webp`，任选其一（`01-dashboard.jpg` 与 `01-dashboard.png` 等效）。
- **本轮已定稿**：16 张界面截图全部收齐；主视觉与分享封面不再单独提供（自动复用首页截图）；手机版 5 张为可选项，暂不提供。

## 二、不再单独提供、自动复用

| 文件名 | 处理方式 |
| --- | --- |
| `00-hero.png` | 首页 Hero 主视觉不再单独提供：按 `01-dashboard` → `02-player` → `03-karaoke` → `04-mtv` → `05-visualizer` → `06-library` → `07-discover` → `08-search` → `09-weather-radio` → `10-detail` → `11-queue` → `12-mine` → `13-settings` → `14-connection` → `15-about` → `16-remote` 的顺序自动复用第一张已就位的截图（当前为 `01-dashboard.png`），并在图上角标注「自动使用 01-dashboard.png」 |
| `00-share-cover.png` | 社交分享封面不再单独提供：`web/index.html` 的 `og:image` / `twitter:image` 直接指向 `/screens/01-dashboard.png` |

> 以后想换成专用横版大图（比如 2560×1440 的电视端首页），把文件放进 `web/public/screens/` 并按 `00-hero.png` / `00-share-cover.png` 命名即可自动顶替，无需改代码。

## 四、维护提示

1. 换图：直接用同名文件覆盖 `web/public/screens/` 下的旧图即可，重新构建后生效。
2. 增图：把文件放进目录并按上表命名，无需改代码；也可在 `web/src/data/screenshots.ts` 中新增槽位（文件名、尺寸、画面内容、可选手机版）。
3. 文件名写错不会影响其它截图，对应位置只会继续显示占位框（框内有文件名、尺寸、画面要点），可逐张修正。
4. 截图里不要出现调试信息；有版权的专辑封面可换占位图；单张建议 ≤ 500KB。
5. 官网「界面预览」页顶部实时显示「已就位 X / 16」，表格逐张标注状态。
